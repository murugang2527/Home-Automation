# Home-Automation
AI-Based Face Recognition Security System with Telegram Alert. Face identification and give alert if stanger will come in side the house


## 1. Introduction

In modern smart homes, security is a major concern. Traditional systems rely on manual monitoring, which is inefficient. This project presents an AI-based face recognition system using deep learning that can identify known individuals and detect unknown persons in real time. When an unknown person is detected, an alert is sent via Telegram.

## 2. Objective

To develop a real-time face recognition system

To identify known and unknown persons

To send alerts for unauthorized access

To enhance home security using AI


## 3. System Overview

The system uses a webcam to capture live video. It compares detected faces with a dataset of known faces using embeddings generated by DeepFace. If a match is found, the person is identified. Otherwise, the system labels them as unknown and sends an alert.


## 4. Methodology

Step 1: Dataset Preparation
Store images of known persons in a folder (dataset)
Each image name represents the person’s identity

Step 2: Face Encoding
Use DeepFace (Facenet model)
Convert images into embeddings (numerical vectors)

Step 3: Real-Time Detection
Capture frames using OpenCV
Extract face embedding from live video

Step 4: Face Matching
Compare live embedding with stored embeddings
Use Euclidean distance for similarity

Step 5: Alert System
If distance > threshold → Unknown person
Send Telegram message using Bot API


## 5. Tools and Technologies

Programming Language: Python

Libraries: OpenCV, DeepFace, NumPy, Requests

Model Used: Facenet

Platform: VS Code

Communication: Telegram Bot API


## 6. Implementation

The system loads known face embeddings at startup. During execution:

Webcam captures live frames

DeepFace extracts facial features

Euclidean distance is calculated

If distance < threshold → Known person

Else → Unknown + Telegram alert

A delay mechanism is used to prevent repeated alerts.
